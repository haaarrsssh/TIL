# TIL

This repository is all about what I learn daily about coding and related topics.
After learning something new, I add it here and then push it to my GitHub account to show my consistency and keep my green contribution streak active.

## Purpose

- Track daily learning progress
- Record coding notes, projects, and discoveries
- Keep a consistent GitHub activity calendar

## How I use this repo

1. Learn something new each day
2. Add notes or code to this repository
3. Push updates to GitHub
4. Keep the green contribution bar growing
